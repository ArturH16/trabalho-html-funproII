# trabalho-html-funproII
Trabalho de HTML, CSS e JS para a disciplina de Fundamentos da Programação II
Tal projeto foi desenvolvido utilizando os conceitos de tags, tabelas, imagens e formulários de HTML
Na parte estilizada, conceitos básicos de design e responsividade com CSS
Na parte interatividade, além do código feito para redirecionar o usuário para outra página caso o login seja bem sucedido ou não, implementei um simples algoritmo para monitorar o horário do sistema a fim de alterar a imagem e a mensagem de acordo com o horário do dia.
* PARA TESTAR FORMULÁRIO *
  O primeiro formulário não faz nada, ele não tem nenhum servidor relacionado a ele para enviar os dados, servindo apenas para testar o label e algumas simples restrições, de obrigatoriedade de preenchimento de todos os inputs e mínimo de 8 caracteres para a senha.
